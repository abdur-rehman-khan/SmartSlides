Help & Instructions

🖐 Hand Gestures

  • Swipe Right — Next slide
  • Swipe Left — Previous slide
  • Open your hand and move it horizontally in front of the camera.
  • Allow camera access and click "Start Camera" to enable.

🎤 Voice Commands

  • next slide / previous slide
  • first slide / last slide
  • read this slide — reads visible text aloud
  • stop reading / pause / resume
  • summarize slide / explain slide
  • start presentation / stop presentation

📁 Uploading Slides

  • Drag & drop a PDF file onto the upload area.
  • Or select multiple PNG / JPG / WebP images.
  • Each PDF page or image becomes one slide.

✦ AI Features

  • Paste your Hugging Face token in the AI panel (optional).
  • Summarize — short summary of slide text.
  • Explain — detailed explanation of slide content.
  • Ask a Question — free-form Q&A about the slide.
  • AI works without a token using a public model (rate limits apply).
